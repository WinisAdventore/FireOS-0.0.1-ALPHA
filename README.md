
# FireOS 

Операционная система с нуля на C и NASM (32-bit)

## Возможности
- VESA фреймбуфер 1920x1080x32
- Мышь PS/2 с курсором
- Оконная система FIOGUI
- Консоль с командами (ls, cd, pwd, mkdir, clear, help, echo, run)
- FAT32 чтение с диска
- Запуск ELF приложений
- Русский шрифт (CP866)
- Клавиатура с Shift/Caps Lock
